# Robotic Arm Video Annotation

## Overview

A personal video annotation project created to showcase robotic arm and object tracking skills using CVAT.

## Tool

* CVAT (Computer Vision Annotation Tool)

## Annotations

* `robot_arm`
* `object`

## Tasks Completed

* Annotated the robotic arm and objects in video frames.
* Tracked movement across frames.
* Adjusted bounding boxes as the arm and objects moved.
* Handled overlapping arm and object bounding boxes.
* Practiced tracking an object while it was being picked up and moved by the robotic arm.

## Dataset

Videos from the University of Strathclyde robotics dataset.

## Project Status

In progress — additional video annotations will be added.
